# Third party notices

The runtime in this package has no third party runtime dependency. Algorithms are original, small implementations of the documented statistics-map contract. The upstream `eurostat-map` checkout retained by the original host repository is optional reference material; it is not required, bundled, imported, or read during builds.

The optional classic browser bundle is generated by esbuild 0.28.2 (MIT), an exact development dependency recorded in package-lock.json. Its installer and native binary are build tools and are not included in dist. The MIT licence is retained in the generated bundle header and dist/licenses/esbuild-MIT.txt. The EUPL-1.2 text included in LICENSE also ships in dist.

The optional preview examples include archived China boundaries from DataV GeoAtlas and selected European country boundaries from Eurostat / GISCO (2024, 1:60M). © EuroGeographics for the administrative boundaries. Their source URLs, hashes, geographic scope and transformations are retained in examples/preview/geometry/*.source.json. The library's EUPL code licence does not replace the boundary sources' own terms. Statistical values shown on these boundaries are synthetic.
